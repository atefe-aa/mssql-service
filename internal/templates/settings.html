Windows Authentication Requirements:

To use Windows Authentication, ensure the following:

  • SQL Server Configuration: SQL Server must be configured for Windows Authentication or Mixed Mode
  • Login Permissions: The Windows account '{{.CurrentUser}}' must exist as a login in SQL Server
  • Database Access: The login must have CONNECT permission to the target database

How to Check in SQL Server:

SELECT name, type_desc, is_disabled FROM sys.server_principals WHERE name = '{{.CurrentUser}}'
